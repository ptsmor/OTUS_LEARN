# Автосервис на Bitrix24 (OTUS, курс Bitrix-разработчик)

Курсовой дипломный проект: модуль **`otus.autoservice`** — гараж клиента в CRM, воронка «Сервисное обслуживание», синхронизация остатков, заявки на закупку услуг и запчастей.

## Стенд

- Демо: `https://ch170762.tw1.ru`

## Что в репозитории

| Путь | Содержание |
|------|------------|
| **`local/modules/otus.autoservice/`** | Модуль (ядро, документация, установщик) |
| **`local/components/otus/contact.garage/`** | Вкладка «Гараж» в контакте |
| **`local/tools/autoservice/`** | Страницы заявок и остатков |
| **`local/php_interface/migrations/`** | Миграции Sprint (HL, воронка, UF) |
